Synchronized charts for CanvasJS

Link zoom, pan, tooltip and crosshair across any number of charts with one call, and keep their plot areas lined up even when the axis labels differ in width.

<script src="https://cdn.canvasjs.com/canvasjs.min.js"></script>
<script src="canvasjs-sync-charts.js"></script>

var sync = CanvasJS.syncCharts([chart1, chart2, chart3]);

Price, volume and momentum

Three charts share one timeline. Drag across any chart to zoom, use the pan button to move, and hover to read all three values for the same day.

  • The price axis has dollar labels, the volume axis has abbreviated numbers. The plot areas still line up.
  • The reset button on any chart resets all of them.
CanvasJS.syncCharts(
  [price, volume, momentum],
  { alignPlotAreas: true }
);

Different sampling rates

Server CPU is sampled every minute, memory every five, and queue depth every fifteen. Hover over the CPU chart and the other tooltips jump to the nearest sample they actually have.

  • snap: "nearest" is the default.
  • Use snap: "exact" to show a tooltip only where an identical x value exists.
CanvasJS.syncCharts(
  [cpu, memory, queue],
  { snap: "nearest" }
);
Samples: 1 min, 5 min and 15 min

Try the options

Turn features on and off, add or remove a chart, or destroy the link and watch each chart return to how it was configured.

  • The three charts use very different value ranges, so turning off alignment shows what it fixes.
  • axisY: "shared" also links the Y range when you zoom on both axes. Drag a box on a chart to try it.
var sync = CanvasJS.syncCharts(charts, {
  zoom: true,
  tooltip: true,
  crosshair: true,
  alignPlotAreas: true,
  axisY: "independent"
});

sync.add(chart4);
sync.remove(chart2);
sync.reset();
sync.destroy();
